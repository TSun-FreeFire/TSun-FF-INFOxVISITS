Security manifesto

Player data is retrieved through temporary network requests. No user credentials are stored by this frontend. Visit automation is a backend action and may be subject to upstream limits or regional rules.

Keep your requests intentional. The desk exposes the same-origin API already present in the Flask app and does not add a new data path.
